# FlowPilot downloads

Official Windows x64 and Apple Silicon macOS downloads for FlowPilot by Vantatech.

## Install

Open [the latest release](https://github.com/vantatech-jeff/FlowPilot-Releases/releases/latest).

- **Windows 11 x64:** download the Setup.exe asset and run it for your user account.
- **Apple Silicon Mac:** download the DMG, open it, and drag FlowPilot.app to Applications.
- FlowPilot downloads its matching Chromium browser through an in-app setup dialog.
- Choose a project folder outside the app installation directory, such as Documents/FlowPilot/projects.

## Updates

Updater-enabled releases check once a day and show an update notification.
Settings → General provides Check for updates, Download update, and Install and restart.
An update never restarts FlowPilot without confirmation. Save your work first.
The app can ask for administrator permission when replacing a Mac app in /Applications.

Older releases require one manual installation of an updater-enabled release.
Windows users upgrading from the previous installer should preserve their project
folder and remove the old installation after confirming the new installation works.

## Distribution status

Early preview packages may be unsigned/ad-hoc signed and show Windows SmartScreen
or macOS Gatekeeper prompts. Signing/notarization status is stated in each release.
Use only releases published in this repository.
